# Electricity Demand Forecasting

This repository contains the code developed for my MSc Advanced Computer Science dissertation at the University of Leeds.

The project investigates machine learning and deep learning approaches for hourly electricity demand forecasting in Romania. The models evaluated include Linear Regression, Random Forest, Extra Trees, Gradient Boosting, Voting Regressor, Multilayer Perceptron (MLP) and Long Short-Term Memory (LSTM).

## Dataset

The dataset used in this project is the *Hourly Electricity Consumption and Production* dataset published by Stefan Comanita on Kaggle.

The dataset contains hourly electricity consumption and production data for Romania, including total production and generation from nuclear, wind, hydroelectric, oil and gas, coal, solar and biomass sources.

Dataset source:
https://www.kaggle.com/datasets/stefancomanita/hourly-electricity-consumption-and-production
